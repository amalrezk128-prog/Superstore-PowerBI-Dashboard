# Superstore Power BI Dashboard

## Project Overview

This project presents an interactive Power BI dashboard designed to analyze sales performance, profitability, orders, and business performance using Superstore data.

The dashboard transforms raw business data into interactive visual insights that help users understand trends, compare performance, and identify key areas of the business.

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Analysis

## Key Analysis

The dashboard provides insights into:

- Sales performance
- Profitability
- Order performance
- Quantity analysis
- Sales trends
- Regional performance
- Customer and product performance

## Dashboard Features

- Interactive KPIs
- Dynamic filters and slicers
- Interactive charts and visualizations
- Trend analysis
- Business performance analysis
- Drill-down and interactive exploration

## Data Preparation

The data was cleaned and transformed using Power Query before building the data model and creating the dashboard.

## Project Files

- `Superstore-PowerBI-Dashboard.pbix` — Power BI dashboard file

## Purpose

The main goal of this project is to demonstrate practical skills in data cleaning, data modeling, DAX, data visualization, and business intelligence using Power BI.
